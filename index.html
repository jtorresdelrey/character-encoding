Laboratorio de bits

Un byte es un paquete de 8 bits. Sumando sus valores, obtenemos el número decimal que representa una letra. Pulsa los bits para cambiar el valor.

Mapa de la evolución de la codificación

Un punto de código es simplemente el número único que el estándar asigna a cada letra o símbolo para identificarlo en su 'diccionario' (tabla o conjunto de caracteres).

El origen

ASCII fue el estándar original de 7 bits. Solo permitía 128 puntos de código, suficientes para el inglés básico pero insuficientes para cualquier otro idioma con tildes o símbolos.

Expansión occidental

Para cubrir las necesidades de Europa Occidental y América, surgieron ampliaciones de 8 bits con 256 puntos de código como ANSI (Windows-1252) y Latin-1 (ISO-8859-1).

El estándar universal

Unicode llegó para unificar todos los alfabetos. Define más de 1.100.000 puntos de código, permitiendo representar cualquier lengua, símbolo científico o emoji de forma universal.

Codificar en...

Acción: INTERPRETAR

Esto es interpretar. No cambias ni un solo bit del archivo; solo le dices al editor: "Oye, prueba con otras gafas". Al elegir la codificación correcta, el texto se arregla mágicamente porque la información siempre estuvo bien.

Convertir a...

Acción: TRANSFORMAR

Esto es transformar. Reescribes físicamente los bytes del archivo. Si usas esto cuando el texto se ve mal, estarás guardando permanentemente la interpretación errónea. ¡El archivo original se perderá para siempre!

Supervivencia en código: escapado

¿Por qué usamos códigos? Porque Unicode es el "pasaporte universal". Al representar un carácter complejo mediante su código numérico básico, blindamos el texto contra errores de interpretación. Así garantizamos que se visualice correctamente en cualquier sistema del mundo.
